-- CHIP-8 Emulator --

An emulator built by me to help learn about emulators in depth.

  COMPONENTS:

  - 16 8-bit registers -
    The CHIP-8 uses sixteen 8-bit registers, V0 to VF. 

  - Instructions -
    This CHIP-8 implementation features ~35 instructions, described below:

    00E0: Clears the screen
    00EE: Return from a subroutine
